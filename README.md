# SimulateKeyboardInput

Windows 键盘输入工具：把文本文件内容或手动编排的操作流程，模拟为键盘输入，发送到当前前台窗口。

- 使用 Windows PowerShell 和 WinForms；无需单独安装 .NET SDK。
- 通过可配置的全局快捷键启动输入，工具不必保持在前台。

## 快速开始

1. 双击 `Run.bat` 启动。
2. 在“文本文件输入”和“手动操作积木”两个操作源中选择一个，并完成相应配置。
3. 如需更改触发键，在窗口顶部的共用快捷键栏点击“修改快捷键”，按下包含 Ctrl、Alt 或 Shift 的组合键并保存。快捷键会保存在当前 Windows 用户配置中，并用于两个操作页。
4. 切换到要接收输入的目标窗口，再按已配置的全局快捷键。

> 手动流程会发往当前前台窗口。启动前请先切换到目标窗口，避免将内容输入到工具自身。

## 文本文件输入

1. 在“文本文件输入”页点击“选择文件...”。
2. 可选勾选“按字符间隔输出”，并设置字符间隔（1–1000 毫秒，默认 50 毫秒）；不勾选时快速输出。
3. 切换到目标窗口，按全局快捷键开始输入。

## 手动操作积木

### 编排流程

在“手动操作积木”页添加积木，并在右侧编辑选中积木的参数。积木按从上到下的顺序执行：

- **输入**：选择输入普通文本，或输入按键/组合键，例如 `Enter`、`PageUp`、`PageDown`、`Home`、`End`、`Ctrl+C`、`Ctrl+PageUp`。
- **等待**：暂停指定秒数，范围为 0.01–3600 秒。
- **循环**：把其他积木拖入循环体；可拖动调整顺序，也支持循环嵌套。

在“按键/组合键”模式下，点击右侧输入框后**直接按下实际按键**，输入框和积木标签会显示对应名称（例如 `PageUp` 或 `Ctrl+PageUp`），新按键会替换上一次记录。Tab、Enter、方向键等也会被记录，而不是移动焦点或编辑文字；此时请用鼠标切换控件。单独按 Ctrl、Alt、Shift 不会替换记录。“文本”模式仍用于正常输入文字，不会把按键名称自动解释为控制键。

每个循环可设置最大次数、最长运行时间，或同时设置两者；任一上限先达到时，该循环就退出。运行时间从进入循环时开始计算，包含循环体中的等待。每项设为 `0` 表示不限，但至少要为每个循环设置一项上限。

### 保存和载入

- 首次点击“保存”时选择 JSON 文件位置；之后“保存”更新当前文件。
- 点击“另存为”选择其他位置，点击“打开 JSON”载入已有流程。
- 手动流程 JSON 当前使用版本号 `1`。

### 运行和停止

选中“手动操作积木”页后，切换到目标窗口并按全局快捷键开始；运行中再次按快捷键或回到面板点击“停止运行”即可取消。等待会及时中断，文本输入会在输入批次边界停止；正在发送的单个按键组合会先完成按下和释放。

## 输入行为与排错

- 文本文件支持 UTF-8（含或不含 BOM）及带 BOM 的 UTF-16/UTF-32。无 BOM 且不是有效 UTF-8 的文件按 Windows 系统 ANSI 编码读取。
- CRLF、LF、CR 换行均模拟为一次 Enter；制表符模拟为 Tab。其它字符通过 Unicode 键盘输入发送，控制字符的表现取决于目标程序。
- 若全局快捷键注册失败，可能是快捷键已被占用；可在“修改快捷键”中更换。
- 如果目标程序以管理员身份运行，通常也需要以管理员身份运行本工具。
- `Run.bat` 是启动器，不是独立程序：它以 STA 模式运行 `SimulateKeyboardInput.ps1`，并只为本次 PowerShell 进程设置执行策略，不会修改系统或用户的持久设置。
